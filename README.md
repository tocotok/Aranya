# ARANYA – Das letzte Zeitalter

3D-Fantasy-JRPG · Dokumentationsrepository

> **Status:** Konzeptphase. Dieses Repository enthält ausschließlich Dokumentation – es wird (noch) nichts programmiert.

| | |
|---|---|
| **Genre** | 3D Fantasy-JRPG |
| **Erzählstil** | Melancholisch, philosophisch, emotional und moralisch komplex |
| **Inspiration** | Klassische JRPGs wie Final Fantasy IX; buddhistische und hinduistische Vorstellungen von Vergänglichkeit, Wiedergeburt und kosmischen Kreisläufen |
| **Geplanter Umfang** | 40–60 Stunden Hauptgeschichte |
| **Spielbare Charaktere** | 8 feste Gruppenmitglieder + 2 Gastmitglieder (nur zeitweise spielbar) |
| **Struktur** | Vier große Handlungsakte |
| **Story-Bibel** | Version 0.4 |

## Grundregel

Offene Fragen ([Kapitel 9](docs/story-bibel/09-offene-fragen.md)) dürfen bei der weiteren Entwicklung **nicht stillschweigend** durch widersprüchliche Annahmen beantwortet werden. Jede neue Festlegung wird in der Story-Bibel dokumentiert und im [Änderungsprotokoll](docs/pflege/aenderungsprotokoll.md) vermerkt.
